# Проект «Лямбда-Синтез» (Lambda-Synthesis)

> **Статус проекта:** Оперативное развертывание (Фаза 1: Статика).  
> **Метаязык:** Idris 2 (интерактивное доказательство теорем).  
> **Целевой объект:** Сертифицированный мета-интерпретатор для строго типизированного, ресурсного (Rust-подобного) подмножества λ-исчисления.

---

## 1. Большая картина (The Big Picture)

Цель проекта — осуществить **Великий Синтез** инженерной практики компиляции и фундаментальной математической логики. Мы строим не просто транслятор строк, а математически доказанную систему, корректность которой гарантирована компилятором Idris до запуска рантайма.

### Разделение миров по Бобу Харперу (PFPL):
1. **Статическая фаза (Statics):** Построение «Железного Дерева» (`Term`). Мы кодируем правила грамматики и типизации нашего языка прямо в индуктивные семейства типов Idris (БНФ на максималках). Некорректную программу физически невозможно сконструировать — Idris отвергнет её как логическое противоречие. Ошибки `NameError` и `TypeError` исключены на корню.
2. **Динамическая фаза (Dynamics):** Тотальное вычисление (`eval`). Функция вычисления освобождена от рантайм-проверок. Ей не нужны динамические таблицы символов (хеш-мапы), проверки типов или обработчики исключений. Вычисление работает как чистый математический трансформатор (элиминатор Мартин-Лёфа), переводящий наши термы в родные функции метаязыка Idris.

## 2. Стратегия и Тактический план

### Шаг 1: Фундамент связывания переменных (Завершено)
* Отказ от строковых имен переменных в пользу **ABT (Abstract Binding Trees)**.
* Использование **индексов Де Брёйна** для кодирования вложенности областей видимости.
* Определение Контекста типизации Гамма ($\Gamma$) как статического вектора типов `Vect n Ty`.
* Кодирование отношения принадлежности `HasType` как конструктивного паспорта переменной через базу индукции (`Here`, индекс 0) и шаг индукции (`There`).

### Шаг 2: Штурм структуры Термов (Текущая задача)
* Сборка индуктивного семейства типов `Term : Context n -> Ty -> Type`.
* Реализация правил введения (Introduction Rules):
  * `Const` — атомарные целочисленные константы (с универсальным контекстным переходником `ctx`).
  * `Var` — узел переменной, жестко требующий паспорт `HasType`.
  * `Abs` — лямбда-абстракция, расширяющая контекст на один шаг каррирования вперед.
  * `App` — аппликация / вызов функции (**В разработке**).

### Шаг 3: Динамика и Семантика
* Определение окружения рантайм-значений `Env`, синхронизированного с контекстом $\Gamma$.
* Реализация тотального элиминатора `eval`, транслирующего `Term` в исполняемые конструкции рантайма Idris.

### Шаг 4: Компаративистика и Философское обобщение
* Анализ систем типов: Idris 2 (Quantitative Type Theory), Rust (Affine Logic), Haskell (System $F_\omega$), Scala 3 (DOT-calculus).
* Теоретическое сведение к единой базе (Харпер, Недерплет).
* Историко-философское осмысление: от кризиса оснований математики, парадокса парикмахера Бертрана Рассела и его Аксиомы сводимости до конструктивного интуиционизма Брауэра («существовать — значит быть построенным»).

## 3. Архитектура Кода (Текущий Слепoк)

```idris
module LambdaInterpreter

import Data.Vect

-- 1. Язык типов (Пространство суждений)
data Ty = TyInt | TyArr Ty Ty

-- 2. Гамма-Контекст (Активные гипотезы)
Context : Nat -> Type
Context n = Vect n Ty

-- 3. Отношение принадлежности (Паспорт переменной)
data HasType : Context n -> Ty -> Type where
    Here  : HasType (t :: ctx) t
    There : HasType ctx t -> HasType (any :: ctx) t
```
